# Xmrig-Script
A few scripts relating to xmrig that i use.
Feel free to use them but dont expect me to debug anything.

You can run the scripts like this:

curl -sSL https://raw.githubusercontent.com/MarcusM2092/Xmrig-Script/main/<SCRIPT_CATEGORY>/<SCRIPT_NAME> | bash


Heres an example:

curl -sSL https://raw.githubusercontent.com/MarcusM2092/Xmrig-Script/main/Installation-Scripts/install-ubuntu.sh | bash
